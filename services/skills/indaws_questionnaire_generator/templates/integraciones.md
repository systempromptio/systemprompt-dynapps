# Cuestionario: Integraciones

*Nota: Completar un cuestionario por cada integracion que se necesite.*

### Sistema Externo

1. **Cual es el nombre del sistema externo que quieren conectar con Odoo?**

2. **Para que se utiliza principalmente este sistema externo? (Ej: Contabilidad, gestion de almacen, plataforma de eCommerce, CRM especifico, etc.)**

### Objetivo Principal

3. **En pocas palabras, cual es la razon mas importante para querer conectar estos dos sistemas? Que problema principal resolveria?**

### Informacion Clave a Compartir

4. **Que tipo de informacion fundamental necesita fluir entre Odoo y el sistema externo? (Ej: Clientes, Pedidos, Productos, Stock, Facturas). Solo los mas importantes:**

### Direccion del Flujo

5. **Principalmente, la informacion ira desde Odoo hacia el sistema externo, desde el sistema externo hacia Odoo, o en ambas direcciones?**

### Frecuencia Deseada

6. **Con que frecuencia aproximada necesitan que esa informacion se actualice entre los sistemas? (Ej: En tiempo real, varias veces al dia, una vez al dia, semanalmente)**

### Capacidad de Conexion

7. **Saben si el sistema externo tiene alguna forma estandar de conectarse con otros programas (como una API)? (Si / No / No estoy seguro)**
