# Post Formats — LinkedIn Best Practices

## Algorithm Priorities (2025-2026)

LinkedIn's algorithm currently favors:
1. **Native content** over external links (posts without links get 2-3x more reach)
2. **Carousels (PDF)** — highest engagement format for company pages
3. **Short-form video** (<90 seconds) — growing fast
4. **Text-only posts** with strong hooks — consistently solid reach
5. **Single image posts** — reliable, lower effort
6. **Link posts** — lowest organic reach (use sparingly, put link in comments when possible)

## Hook Patterns That Work

The first 2 lines determine if people click "ver mas". Use these patterns:

### Pattern 1: Contrarian Statement
```
La mayoria de empresas implementan un ERP para "digitalizar procesos."
Eso es exactamente lo que NO deberian hacer.
```

### Pattern 2: Specific Number
```
92 empresas han transformado su gestion con Odoo en los ultimos 3 anos.
Esta es la leccion que mas se repite.
```

### Pattern 3: Story Opening
```
El director financiero nos llamo un viernes a las 18:00.
"Necesitamos esto funcionando el lunes."
```

### Pattern 4: Question That Challenges
```
Si tu equipo necesita 3 dias para cerrar el mes contable,
el problema no es tu equipo.
```

### Pattern 5: Before/After
```
Antes: 47 hojas de Excel para gestionar inventario.
Ahora: un dashboard en tiempo real.
```

## Post Length Guidelines

| Type | Ideal Length | Max |
|------|-------------|-----|
| Case study | 150-250 words | 300 |
| Odoo pill | 80-150 words | 200 |
| Behind the scenes | 100-200 words | 250 |
| Opinion | 200-350 words | 400 |
| Podcast promo | 80-150 words | 200 |
| Carousel cover text | 30-50 words | 80 |

## CTA Patterns

End posts with engagement drivers:

**Questions** (best for comments):
- "Cual ha sido tu mayor reto en [tema]?"
- "Te ha pasado algo parecido?"
- "Que opinas?"

**Soft CTAs** (for link/case content):
- "El caso completo esta en los comentarios."
- "Si quieres ver como lo hicimos, el enlace esta abajo."

**Avoid hard sells**: Never "Contactanos" or "Pide presupuesto" in organic posts.

## Visual Specifications

### Single Image
- **Size**: 1200x1200 (square, best engagement) or 1200x628 (landscape)
- **Format**: PNG or JPG
- **Text on image**: Minimal. Max 20% of image area.
- **Brand**: Use dynapps-brand colors. Montserrat for any text overlay.

### Carousel (PDF)
- **Size**: 1080x1350 per slide (portrait, optimized for mobile)
- **Slides**: 5-10 (sweet spot: 7-8)
- **Structure**:
  - Slide 1: Bold title + hook. Full branded background (Blue Space or gradient).
  - Slides 2-N: One idea per slide. Clean layout. Large text.
  - Final slide: CTA + Indaws logo + web URL
- **Font size**: Min 24pt for body, 36pt+ for titles
- **Brand**: Full dynapps-brand compliance (colors, Montserrat, logo rules)

### Video
- **Duration**: 30-90 seconds ideal
- **Format**: MP4, square (1:1) or vertical (9:16)
- **Subtitles**: Always. 85% of LinkedIn video is watched muted.
- **Branding**: Indaws watermark/logo in corner

### Team Photos
- **Always real photos**. Never AI-generated for people/team content.
- **Edit**: Light brand overlay acceptable (logo corner, color filter)
- **Context**: Show real work environments, events, celebrations

## Content Mix Benchmarks (Funnel-Aligned)

Optimal weekly mix for B2B company pages (5 posts):

| Funnel | Posts/Week | Types | Purpose |
|--------|-----------|-------|---------|
| **TOFU** | 2 | Opinion, pill, culture, edu carousel | Attract, reach |
| **MOFU** | 2 | Case study, podcast, Indaws carousel, "how we do it" | Trust, authority |
| **BOFU** | 1 | Results, diagnostic, event, demo | Convert, generate leads |

**Key rule**: BOFU never before at least 2 TOFU/MOFU posts that week.
Never put link in the post body — always in first comment (better algorithm reach).

## Posting Schedule

Best times for B2B LinkedIn in Spain:
- **Tuesday to Thursday**: 9:00-10:00 CET (peak)
- **Monday**: 10:00-11:00 CET
- **Friday**: 9:00-10:00 CET (lower but acceptable)
- **Avoid**: Weekends, after 18:00, before 8:00

Space posts minimum 24h apart. Never post twice in one day.
