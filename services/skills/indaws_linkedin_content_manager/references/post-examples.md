# Post Examples by Funnel Stage

Worked examples per post type. Use as copy/visual-brief models. Pair with
`post-formats.md` (hooks, length, CTA, visual specs) and `funnel-strategy.md`
(when/why each stage). Preview any draft with `templates/post-preview-card.html`.

Funnel colors: TOFU `#8AC2DB` (Light Sky) · MOFU `#6B68FA` (Blue Lilac) · BOFU `#E5B92B` (Warm Yellow).

---

## TOFU: Píldora Odoo

**Objetivo**: Educar, atraer nuevos seguidores. **Longitud**: 80-150 palabras.

```
┌────────────────────────────────────────────────────────────┐
│  TOFU                                        #8AC2DB        │
├────────────────────────────────────────────────────────────┤
│  Si tu equipo de compras gestiona pedidos por WhatsApp,    │
│  el problema no es tu equipo.                              │
│                                                            │
│  Es un síntoma de que tu sistema no está diseñado para    │
│  cómo trabaja la gente de verdad.                          │
│                                                            │
│  Un ERP bien implementado convierte esos mensajes en       │
│  pedidos automáticos:                                      │
│  - El proveedor recibe el pedido sin intervención          │
│  - El stock se actualiza solo                              │
│  - Compras ve todo en un dashboard                         │
│                                                            │
│  No es magia. Es diseñar procesos pensando en personas.   │
│                                                            │
│  Tu equipo de compras, cómo gestiona los pedidos hoy?     │
├────────────────────────────────────────────────────────────┤
│  Visual: Diagrama flujo WhatsApp → Odoo → Proveedor        │
│  Dims: 1200x1200 | Herramienta: Canva                      │
└────────────────────────────────────────────────────────────┘
```

## TOFU: Opinión / Tendencia

**Objetivo**: Posicionamiento thought leadership. **Longitud**: 200-350 palabras.

```
┌────────────────────────────────────────────────────────────┐
│  TOFU                                        #8AC2DB        │
├────────────────────────────────────────────────────────────┤
│  La mayoría de empresas digitalizan para "modernizarse".  │
│  Y eso es exactamente el enfoque equivocado.               │
│                                                            │
│  Digitalizar no es cambiar Excel por software.             │
│  Es rediseñar cómo fluye la información en tu empresa.     │
│                                                            │
│  He visto empresas con ERPs de última generación que       │
│  siguen imprimiendo albaranes para que alguien los         │
│  "pique" a mano en el sistema.                             │
│                                                            │
│  Y he visto talleres con herramientas básicas donde        │
│  el operario escanea una pieza y toda la cadena se         │
│  entera en tiempo real.                                    │
│                                                            │
│  La diferencia no es el software.                          │
│  Es si alguien se sentó a pensar:                          │
│  - Quién necesita esta información                         │
│  - En qué momento                                          │
│  - Para tomar qué decisión                                 │
│                                                            │
│  Antes de elegir tecnología, elige diseño de procesos.     │
│                                                            │
│  Tu empresa digitaliza o realmente transforma?             │
├────────────────────────────────────────────────────────────┤
│  Visual: Quote card "El software no transforma. El        │
│          diseño de procesos sí."                           │
│  Dims: 1200x1200 | Branded: Blue Space + Montserrat        │
└────────────────────────────────────────────────────────────┘
```

## MOFU: Caso de Éxito

**Objetivo**: Construir confianza con prueba social. **Longitud**: 150-250 palabras.

```
┌────────────────────────────────────────────────────────────┐
│  MOFU                                        #6B68FA        │
├────────────────────────────────────────────────────────────┤
│  "Cerramos el mes en 4 horas. Antes eran 3 días."         │
│  Eso nos dijo la directora financiera de Espacio Orgánico.│
│                                                            │
│  Cuando llegamos, tenían:                                  │
│  - 3 tiendas físicas con inventarios separados             │
│  - Contabilidad en hojas de cálculo                        │
│  - Cero visibilidad de stock entre locales                 │
│                                                            │
│  Lo que implementamos:                                     │
│  - Odoo unificando punto de venta + inventario             │
│  - Stock sincronizado en tiempo real                       │
│  - Contabilidad integrada con ventas                       │
│                                                            │
│  El resultado:                                             │
│  - Cierre mensual de 3 días a 4 horas                      │
│  - Reabastecimiento automático entre tiendas               │
│  - Directora financiera con dashboards en vez de Excel     │
│                                                            │
│  El caso completo está en los comentarios.                 │
├────────────────────────────────────────────────────────────┤
│  Comentario: [Link al caso en web/YouTube]                 │
│  Visual: Foto cliente + frame Indaws con métrica clave     │
│  Dims: 1200x1200 | Herramienta: Canva + foto real          │
└────────────────────────────────────────────────────────────┘
```

Fuente de casos: `content-collection` (casos de éxito, vídeos, módulos).

## BOFU: Diagnóstico / Resultados

## Content Series (Secuencias de Funnel)

Secuencias multi-semana que guían a la audiencia a través del funnel:

```
SEMANA N
├── Día 1 (TOFU): "Los 5 errores más comunes al implementar un ERP"
└── Día 3 (MOFU): "Cómo resolvimos estos errores con [Cliente X]"

SEMANA N+1
└── Día 1 (BOFU): "Diagnóstico gratuito: tu empresa tiene estos síntomas?"
```

**Máximo 2 series activas simultáneamente.**
