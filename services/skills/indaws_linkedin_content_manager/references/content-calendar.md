# Content Calendar — Template and Workflow

## Weekly Planning Process

1. **Monday morning**: Run discovery (Phase 1) to gather fresh content ideas
2. **Monday**: Plan the week's 3-5 posts using the template below
3. **Tuesday-Friday**: Create and schedule posts according to calendar
4. **Friday afternoon**: Review week's performance metrics

## Mix Validation Checklist

Before finalizing a week's calendar, verify:

- [ ] At least 1 case study or client reference
- [ ] At least 1 educational content (pill or carousel)
- [ ] At least 1 culture/team post
- [ ] No 2 consecutive posts of the same type
- [ ] No more than 1 podcast/video promo
- [ ] Posts spread across Tue-Thu (core), Mon/Fri (optional)
- [ ] Each post has a defined visual type

## Monthly Themes (Optional)

Align weeks with business calendar when relevant:

| Trigger | Content Opportunity |
|---------|-------------------|
| New case study published | Case study post + carousel deep-dive |
| Podcast episode released | Promo post + quote cards |
| Odoo version release | Technical pill + opinion on new features |
| Indaws event (past) | Behind-the-scenes photo + recap |
| Indaws event (upcoming) | Announcement + countdown |
| Industry event (Odoo Experience, etc.) | Live coverage + takeaways |
| Team milestone | Culture post |
| Quarter close | Results/growth post |
