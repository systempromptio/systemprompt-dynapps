# Task Templates — Odoo Project Tasks

Standard tasks auto-created for each event project.
Each task has: name, stage, assignee suggestion, deadline offset, description.

Deadline offsets are relative to event date (T-0).

---

## Stage: Planificacion

| Task | Deadline | Assignee | Description |
|------|----------|----------|-------------|
| Definir objetivo y KPIs | T-8 weeks | Victor | Establecer que queremos conseguir: leads, brand, retention. Definir metricas de exito. |
| Confirmar fecha y venue | T-7 weeks | Marketing | Visitar venue si es nuevo. Confirmar capacidad, AV, catering, parking. Firmar reserva. |
| Confirmar speaker(s) | T-7 weeks | Victor | Bio, foto profesional, tema de la presentacion, necesidades tecnicas. |
| Definir presupuesto | T-7 weeks | Victor | Desglose por categorias (venue, catering, materiales, AV, promo, imprevistos). Aprobacion. |
| Contactar co-organizadores | T-6 weeks | Victor | Alinear roles, costes compartidos, promocion cruzada, lista de invitados. |
| Crear evento en Odoo | T-6 weeks | Marketing | Evento en modulo Events: nombre, fecha, venue, capacidad, tickets, formulario registro. |
| Disenar landing page | T-6 weeks | Marketing | Pagina de registro en web con info del evento, speaker, agenda, formulario. |
| Crear lista de invitados | T-6 weeks | Marketing | Exportar de CRM + base de datos + co-organizador. Segmentar por prioridad. |

## Stage: Preparacion

| Task | Deadline | Assignee | Description |
|------|----------|----------|-------------|
| Confirmar catering | T-1 week | Marketing | Headcount final (registros + 10% buffer). Menu, alergias, horarios. |
| Confirmar AV con venue | T-1 week | Marketing | Proyector, pantalla, micro, altavoces, WiFi. Testear si posible. |
| Finalizar presentacion | T-1 week | Victor | Deck final. Ensayar timing (max 30-40 min para dejar espacio a Q&A y networking). |
| Preparar materiales fisicos | T-1 week | Marketing | Roll-ups, folletos, tarjetas visita, badges, merchandising. |
| Preparar check-in list | T-3 days | Marketing | Lista de asistentes confirmados. App o hoja impresa. |
| Asignar roles dia del evento | T-3 days | Marketing | Quien hace que: host, registro, foto, logistica, networking. |
| Preparar formulario feedback | T-3 days | Marketing | Google Form o Odoo Survey. 5 preguntas max. QR code impreso. |
| Enviar recordatorio final | T-2 days | Marketing | Email a registrados: fecha, hora, direccion, parking, que esperar. |
| Testear tech | T-1 day | Marketing | Laptop + proyector + clicker + backup USB + WiFi. |

## Stage: Ejecucion

| Task | Deadline | Assignee | Description |
|------|----------|----------|-------------|
| Montaje venue | T-0 (2h antes) | Marketing | Roll-ups, senyalizacion, mesa registro, catering setup, AV check. |
| Registro asistentes | T-0 (30min antes) | Marketing | Check-in, badges, bienvenida. Marcar asistencia en Odoo. |
| Bienvenida | T-0 | Host | Presentar Indaws, co-organizador, speaker, agenda. 5 min max. |
| Presentacion | T-0 | Speaker | Charla principal. 30-40 min. |
| Q&A | T-0 | Host | Moderar preguntas. 15-20 min. |
| Networking | T-0 | Equipo | Facilitar conversaciones. Recoger tarjetas. Identificar leads calientes. |
| Fotos | T-0 | Asignado | Fotos de sala, speaker, asistentes, networking, branding. |
| Recoger feedback | T-0 (al cierre) | Marketing | QR a formulario, pedir que rellenen antes de irse. |
| Desmontaje | T-0 (despues) | Marketing | Recoger materiales, devolver venue en orden. |
