# Event Timeline — Week-by-Week Planning

Standard timeline for Indaws business events (conferences, breakfasts).
Adjust for urgency — minimum viable planning is 3 weeks.

---

## T-8 to T-6 Weeks: IDEA & SETUP

### Week 1-2: Foundation
- [ ] Define event concept, theme, and title
- [ ] Set date (check calendar conflicts: holidays, competitor events, team availability)
- [ ] Confirm venue (visit if new venue, confirm capacity, AV, parking)
- [ ] Confirm speaker(s) — bio, photo, presentation topic
- [ ] Define target audience and invite list
- [ ] Set budget and get approval
- [ ] Identify co-organizers (if applicable) — align on roles, costs, promotion
- [ ] Create Odoo Event + Odoo Project (run create_event_project.py)
- [ ] Design event landing page / registration form

**Deliverables**: Event in Odoo, project with all tasks, budget approved.

---

## T-5 to T-4 Weeks: PROMOTION LAUNCH

### Week 3-4: Get the Word Out
- [ ] Design visual materials:
  - Event invitation (digital — email + LinkedIn)
  - Banner/header for web
  - Speaker card for social media
  - Printed materials brief (if needed)
- [ ] Write email invitation copy (brand-compliant)
- [ ] Plan LinkedIn promotion sequence (4 posts — see linkedin-content-manager)
- [ ] Send first email invitation wave (entire invite list)
- [ ] Publish first LinkedIn post (announcement)
- [ ] Activate registration on web
- [ ] Contact media / press (if applicable)
- [ ] If co-organized: align on cross-promotion plan

**Deliverables**: Registration live, first emails sent, first LinkedIn post published.

---

## T-3 Weeks: PROMOTION PUSH

### Week 5: Build Momentum
- [ ] Publish LinkedIn post #2 (speaker spotlight / what you'll learn)
- [ ] Send second email wave (to non-opens from first wave)
- [ ] Personal invitations (phone/WhatsApp) to VIPs and key prospects
- [ ] Monitor registration pace — if below target, increase promotion
- [ ] Prepare speaker presentation deck (first draft)
- [ ] Order printed materials (if needed — allow delivery time)

**Deliverables**: >50% capacity registered, presentation draft.

---

## T-2 Weeks: PREPARATION

### Week 6: Lock Everything Down
- [ ] Publish LinkedIn post #3 (urgency — "quedan X plazas")
- [ ] Send reminder email to registered attendees (logistics: address, parking, schedule)
- [ ] Send "last chance" email to non-registered
- [ ] Confirm catering order (headcount based on registrations + 10% buffer)
- [ ] Confirm AV setup with venue (projector, screen, microphone, speakers)
- [ ] Finalize presentation deck
- [ ] Design name badges (if applicable)
- [ ] Prepare attendee check-in list
- [ ] Assign day-of roles to team (host, registration, photo, logistics)
- [ ] Prepare feedback form (Google Form or Odoo survey)

**Deliverables**: All logistics confirmed, presentation final, team briefed.

---

## T-1 Week: FINAL PREP

### Week 7: Last Details
- [ ] Publish LinkedIn post #4 (final push)
- [ ] Send final reminder email (48h before)
- [ ] Print badges and materials
- [ ] Prepare event kit (roll-ups, branded items, business cards)
- [ ] Brief speaker on schedule, timing, Q&A format
- [ ] Test all tech (laptop, projector compatibility, clicker, backup USB)
- [ ] Confirm final headcount with venue/catering
- [ ] Prepare photography shot list

**Deliverables**: Everything ready, no loose ends.

See [day-of-checklist.md](day-of-checklist.md) for detailed execution.

---

## T+2 Days: IMMEDIATE FOLLOW-UP

- [ ] Send thank-you email to attendees (with presentation PDF, photos)
- [ ] Send "we missed you" email to no-shows (with key takeaway)
- [ ] Publish LinkedIn recap post (photo + key insight)
- [ ] Upload photos to shared drive
- [ ] Create CRM leads from attendees (non-clients)
- [ ] Tag leads in CRM: "Evento [nombre] [fecha]"
- [ ] Quick debrief with team (what worked, what didn't)

---

## T+1 Week: MEASUREMENT & LEARNING

- [ ] Review registration vs attendance rate
- [ ] Count new leads generated
- [ ] Calculate cost per lead (budget / leads)
- [ ] Review feedback survey results
- [ ] Publish blog post recap (if applicable)
- [ ] Start lead nurturing sequence (commercial follow-up)
- [ ] Document lessons learned in event data
- [ ] Update this timeline/process if needed
- [ ] Close Odoo project (all tasks done)

---

## Compressed Timeline (3-4 Weeks)

For urgent events, compress to minimum viable:

| Week | Focus |
|------|-------|
| Week 1 | Setup + design + first promotion |
| Week 2 | Promotion push + speaker prep |
| Week 3 | Final logistics + last promotion |
| Week 4 | Event + follow-up |

Cut: printed materials, media outreach, multiple email waves. Focus on LinkedIn + direct invitations.
