## Budget Rules

1. **Always include 10% buffer** for unexpected costs
2. **Track real vs estimated** — fill "Real" column after the event
3. **Negotiate venue rates** for recurring events (20-24/year = leverage)
4. **Reuse materials** — roll-ups, branded items across events
5. **Cost per attendee** = total budget / confirmed attendees
6. **Cost per lead** = total budget / new leads generated

## Scaling Budget

| Event Size | Budget Range | Notes |
|------------|-------------|-------|
| 20 pax (breakfast) | 500-1000 | Basic: venue + catering + materials |
| 50 pax (conference) | 1000-2500 | Add: better AV, more catering, printed materials |
| 100+ pax (summit) | 3000-8000 | Add: external speakers, video production, ads |

## Co-Organized Events

When co-organizing with another entity:
- **Split costs**: Define split upfront (50/50, or proportional to invite list)
- **Track separately**: Each party's costs in their own column
- **Shared items**: Venue and catering usually split; materials separate
- **Revenue sharing**: If ticketed event, define split in advance
