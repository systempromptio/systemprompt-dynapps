# Day-of Execution Checklist

Minute-by-minute rundown for event day.
Adapt timing to your specific event schedule.

---

## Standard Schedule: Business Breakfast (3h event)

### T-2h: Montaje (equipo llega)
- [ ] Llegar al venue, contactar responsable del espacio
- [ ] Verificar sala: mesas, sillas, disposicion correcta
- [ ] Montar roll-ups e identidad visual Indaws
- [ ] Preparar mesa de registro (lista asistentes, badges, bolis)
- [ ] Setup AV: conectar portatil, probar proyector, probar micro
- [ ] Tener backup presentacion en USB
- [ ] Comprobar WiFi (password para asistentes)
- [ ] Verificar catering: timing de servicio, ubicacion, alergias
- [ ] Colocar materiales en mesas (folletos, tarjetas, merchandising)
- [ ] Tomar foto de la sala montada (antes de que llegue gente)

### T-30min: Pre-Evento
- [ ] Equipo en posiciones (registro, bienvenida, foto)
- [ ] Speaker hace check final de presentacion en pantalla
- [ ] Catering listo para servir (desayuno disponible a la llegada)
- [ ] Abrir puertas

### T-0: Registro y Bienvenida (30 min)
- [ ] Recibir asistentes en la puerta
- [ ] Check-in: nombre, badge, marcar asistencia
- [ ] Dirigir a zona de desayuno/networking
- [ ] Hacer fotos de llegada y networking inicial
- [ ] Si co-organizado: presentar equipos entre si

### T+30min: Inicio Formal (5 min)
- [ ] Host da la bienvenida
- [ ] Presentar Indaws brevemente (1 min)
- [ ] Presentar co-organizador si aplica (1 min)
- [ ] Presentar speaker (1 min)
- [ ] Explicar agenda y duracion

### T+35min: Presentacion (30-40 min)
- [ ] Speaker presenta
- [ ] Controlar tiempo (aviso a 5 min del final)
- [ ] Fotos del speaker y audiencia
- [ ] No interrumpir salvo emergencia

### T+1h15min: Q&A (15-20 min)
- [ ] Host modera preguntas
- [ ] Si nadie pregunta: tener 2-3 preguntas preparadas
- [ ] Limitar preguntas largas: "Gran pregunta, podemos profundizar en el networking"
- [ ] Cerrar Q&A con agradecimiento

### T+1h35min: Networking (30-45 min)
- [ ] Invitar a seguir con cafe/networking
- [ ] Equipo Indaws circula y facilita conversaciones
- [ ] Identificar leads calientes (anotar mentalmente o en movil)
- [ ] Intercambiar tarjetas / LinkedIn
- [ ] Fotos de networking

### T+2h15min: Cierre
- [ ] Host agradece asistencia
- [ ] Recordar: "Recibireis la presentacion por email"
- [ ] Pedir que rellenen feedback (mostrar QR)
- [ ] Despedida

### T+2h30min: Desmontaje
- [ ] Recoger roll-ups y materiales
- [ ] Recoger badges no recogidos (lista de no-shows)
- [ ] Comprobar que no queda nada personal del equipo
- [ ] Agradecer al venue
- [ ] Foto final del equipo (si queda gente)

---

## Kit del Evento (traer)

### Imprescindible
- [ ] Portatil con presentacion
- [ ] USB backup con presentacion
- [ ] Adaptadores video (HDMI, USB-C, DisplayPort)
- [ ] Clicker / puntero presentacion
- [ ] Lista asistentes impresa
- [ ] Badges (si aplica)
- [ ] Roll-up Indaws
- [ ] Tarjetas de visita
- [ ] Movil cargado (fotos, WhatsApp)
- [ ] QR feedback form impreso

### Recomendado
- [ ] Alargador electrico
- [ ] Cinta adhesiva / blue-tack
- [ ] Rotuladores gruesos (para badges manuales)
- [ ] Folletos Indaws
- [ ] Merchandising (libretas, bolis)

---

## Emergencias

| Situacion | Solucion |
|-----------|----------|
| Proyector no funciona | Usar TV del venue / compartir pantalla en tablets / presentar sin slides |
| Speaker llega tarde | Extender networking inicial, reorganizar agenda |
| Pocos asistentes | No mencionar, adaptar disposicion de sala a grupo mas intimo |
| Demasiados asistentes | Anadir sillas, pedir mas catering, gestionar flujo |
| Wifi no funciona | Hotspot movil para lo esencial |
| Catering no llega | Cafe de emergencia (pedir al venue), reordenar agenda |
