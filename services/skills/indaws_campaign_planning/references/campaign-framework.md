# Campaign Framework — Indaws

## Framework Overview

Toda campana de marketing Indaws sigue un framework de cinco partes:

```
┌────────────────────────────────────────────────────────────────┐
│                     CAMPAIGN FRAMEWORK                          │
├────────────────────────────────────────────────────────────────┤
│                                                                  │
│   OBJECTIVE          AUDIENCE          MESSAGE                   │
│   (Que lograr)       (A quien)         (Que decir)               │
│       │                  │                 │                     │
│       ▼                  ▼                 ▼                     │
│   ┌────────┐       ┌────────┐        ┌────────┐                │
│   │ SMART  │       │ Buyer  │        │ Value  │                │
│   │ Goal   │       │Persona │        │ Prop.  │                │
│   └────────┘       └────────┘        └────────┘                │
│                                                                  │
│   CHANNEL               MEASURE                                 │
│   (Donde)                (Como saber)                            │
│       │                      │                                  │
│       ▼                      ▼                                  │
│   ┌────────┐           ┌────────┐                              │
│   │ Owned  │           │  KPIs  │                              │
│   │Channels│           │+ Tools │                              │
│   └────────┘           └────────┘                              │
│                                                                  │
└────────────────────────────────────────────────────────────────┘
```

## SMART Objectives

Cada campana necesita un objetivo que sea Specific, Measurable, Achievable, Relevant, Time-bound.

### Ejemplos de Objetivos Indaws

| Tipo de Campana | Objetivo SMART |
|-----------------|----------------|
| Lead generation | Generar 30 leads cualificados para implantacion Odoo en Q2 2026 |
| Event promotion | Conseguir 40 registros para el desayuno de IA Aplicada el 20 de marzo |
| Brand awareness | Aumentar seguidores de LinkedIn de 1.200 a 1.800 en 6 meses |
| Content / SEO | Incrementar trafico organico del blog un 40% en Q3 vs Q2 |
| Nurturing | Convertir 15% de leads frios en MQLs via secuencia de 4 emails en 2 meses |
| Reactivation | Reactivar 20 clientes V16 para migrar a V20 con campana de 4 meses |
| Product launch | Generar 25 demos de Indaws Core BI en el primer mes post-lanzamiento |

## Buyer Personas

| Persona | Rol tipico | Pain points | Canal preferido | Funnel entry |
|---------|-----------|-------------|-----------------|--------------|
| **Decision Maker** | CEO, Director General, CFO | Falta de visibilidad, ineficiencias, coste de no digitalizar | Eventos, LinkedIn, email personal | BOFU |
| **Influencer Tecnico** | CTO, IT Manager, Responsable sistemas | Integracion, mantenimiento, escalabilidad | Blog, LinkedIn, webinars | MOFU |
| **Usuario Final** | Director operaciones, Jefe compras, Controller | Procesos manuales, doble entrada, Excel | Blog, email, demos | TOFU/MOFU |
| **Partner Referral** | Consultor, asesor fiscal, empresa complementaria | Buscar soluciones para recomendar a clientes | Eventos, LinkedIn | MOFU |

## Campaign Launch Checklist

```
ESTRATEGIA
[ ] Objetivo SMART definido
[ ] Buyer persona identificado
[ ] Mensaje / propuesta de valor clara
[ ] Canales seleccionados (con prioridad)
[ ] KPIs y targets definidos
[ ] Presupuesto asignado

CONTENIDO
[ ] Content calendar creado (semanal)
[ ] Templates seleccionados para cada pieza
[ ] Briefs de contenido asignados a responsables
[ ] Assets visuales planificados
[ ] Calendario revisado por equipo

EJECUCION
[ ] LinkedIn posts en borrador / programados
[ ] Emails creados en Odoo (estado DRAFT)
[ ] Landing pages publicadas y testeadas
[ ] Blog posts programados
[ ] Eventos creados en Odoo Events (si aplica)
[ ] Formularios conectados a CRM

MEDICION
[ ] Dashboard de KPIs configurado
[ ] Baseline (datos antes de campana) registrado
[ ] UTMs configurados para tracking
[ ] Fecha de revision intermedia definida
[ ] Fecha de informe final definida
```

## Campaign Types Quick Reference

### Awareness
```
Duracion: 4-8 semanas continuas
Canales: LinkedIn (primario) + Blog (soporte)
Contenido: 20-40 posts LinkedIn + 4-8 blog posts
Presupuesto: 0-200 EUR
KPI principal: Impresiones + nuevos seguidores
```

### Lead Gen
```
Duracion: 4-6 semanas
Canales: Eventos (primario) + Email (soporte) + LinkedIn (amplificacion)
Contenido: 1-2 eventos + secuencia 3-4 emails + 5-10 LinkedIn posts
Presupuesto: 1.000-3.000 EUR
KPI principal: Leads cualificados generados
```

### Evento
```
Duracion: 8 semanas (6 pre + 2 post)
Canales: Email (primario) + LinkedIn (primario) + Landing page
Contenido: 3+1 emails + 5 LinkedIn posts + 1 landing page
Presupuesto: 500-3.000 EUR
KPI principal: Asistentes + leads post-evento
```

### Product Launch
```
Duracion: 4-6 semanas
Canales: Todos (LinkedIn + Email + Blog + Landing + Evento)
Contenido: Full mix across all channels
Presupuesto: 1.000-3.000 EUR
KPI principal: Demos solicitadas + pipeline generado
```

### Nurturing
```
Duracion: 2-4 meses
Canales: Email (primario) + LinkedIn (soporte)
Contenido: Secuencia 5-7 emails + contenido soporte LinkedIn
Presupuesto: 0 EUR (Odoo incluido)
KPI principal: Leads que avanzan stage en pipeline
```
