# Budget Guide — Indaws Marketing

Indaws tiene un modelo de marketing de bajo coste: contenido interno + eventos presenciales. Sin publicidad de pago.

---

## Budget por Tipo de Gasto

| Categoria | Presupuesto tipico | Notas |
|-----------|-------------------|-------|
| Eventos presenciales | 1.000-3.000 EUR/evento | Venue, catering, materiales, AV |
| Catering eventos | 10-25 EUR/persona | Desayunos: 10-15 EUR, conferencias: 15-25 EUR |
| Venue alquiler | 0-500 EUR/evento | Muchos gratuitos via partners o coworkings |
| Materiales impresos | 100-300 EUR/evento | Roll-ups, tarjetas, carpetas |
| Herramientas SaaS | ~100 EUR/mes | Canva Pro ~13 EUR/mes, DataForSEO ~50 EUR/mes, analytics |
| Contenido interno | 0 EUR | Produccion interna: blog, LinkedIn, email |
| Fotografia/Video | 0-500 EUR/evento | Interno cuando posible, externo para conferencias grandes |
| Lead enrichment | ~50 EUR/mes | Tomba.io, Brave Search API |

---

## Budget por Tipo de Campana

| Tipo campana | Presupuesto total | Desglose principal |
|-------------|-------------------|-------------------|
| Brand awareness (Q) | 0-200 EUR | Solo herramientas SaaS |
| Lead generation (Q) | 500-2.000 EUR | 1-2 eventos + materiales |
| Event series (Q) | 3.000-9.000 EUR | 3-6 eventos x 1.000-1.500 EUR |
| Product launch | 1.000-3.000 EUR | 1 evento + materiales + landing page |
| Content / SEO (Q) | 50-100 EUR | Solo DataForSEO |
| Nurturing (Q) | 0 EUR | Todo via Odoo Email Marketing (incluido en licencia) |

---

## ROI Calculation

```
ROI de campana = (Revenue generado - Coste campana) / Coste campana x 100

Revenue generado:
├── Leads cualificados x Tasa de conversion x Ticket medio
│
│   Ejemplo: 30 leads x 20% conversion x 15.000 EUR = 90.000 EUR
│   Coste campana: 3.000 EUR
│   ROI: (90.000 - 3.000) / 3.000 x 100 = 2.900%

Nota: El ROI de marketing en B2B se mide a 90-180 dias (ciclo de venta largo)
```
