# Content Vocabulary — Indaws Terminology Rules

## Core Vocabulary Table

| Usar | Evitar | Razon |
|------|--------|-------|
| inversion | coste, precio | Enmarca el ERP como retorno, no gasto |
| reto | problema, dificultad | Lenguaje constructivo, no alarmista |
| acompanamiento | soporte, atencion al cliente | Refleja la relacion consultora |
| evolucion continua | actualizaciones, mantenimiento | Posiciona el servicio como estrategico |
| especialistas | tecnicos, informaticos | Eleva el perfil del equipo |
| propuesta | oferta, presupuesto | Mas consultivo, menos transaccional |
| ordenador | computadora | es-ES vs es-LATAM |
| movil | celular | es-ES vs es-LATAM |
| tu empresa | su empresa | Tratamiento de tu, nunca usted |

## Language Rules (es-ES)

| Regla | Correcto | Incorrecto |
|-------|----------|------------|
| Tratamiento | "tu", "tu empresa" | "usted", "su empresa", "vosotros" |
| Acentos | siempre obligatorios | omitir en mayusculas o tecnicismos |
| Signos apertura | ¿pregunta? ¡exclamacion! | ?pregunta? !exclamacion! |
| Variante regional | "ordenador", "movil" | "computadora", "celular" |
| Anglicismos | usar equivalente espanol si existe | usar ingles cuando hay alternativa clara |

## Brand Voice Attributes

| Atributo | Descripcion |
|----------|-------------|
| Experto cercano | Conocimiento profundo sin condescendencia |
| Orientado a negocio | Hablar de resultados, ROI, impacto real |
| Directo | Sin rodeos, sin relleno, mensaje claro |
| Confiable | Datos, casos reales, sin hiperboles |
| Empático | Reconocer el reto antes de vender la solucion |

## Hard Format Rules

| Elemento | Regla |
|----------|-------|
| Emojis | CERO. Prohibidos en todo contenido oficial |
| Hashtags | CERO en LinkedIn. Prohibidos |
| Autopromocion directa | Evitar. El valor debe ser evidente, no anunciado |
| Clickbait | Prohibido. Titulos deben cumplir lo que prometen |
| Ingles en contenido ES | Solo terminos tecnicos sin equivalente aceptado |

## Quality Checklist (Pre-Publication)

```
MARCA
[ ] Voz: experto cercano, "tu", sin condescendencia
[ ] Vocabulario: terminos Indaws (inversion, reto, acompanamiento, evolucion continua, especialistas, propuesta)
[ ] Sin emojis
[ ] Sin hashtags (en LinkedIn)
[ ] Colores y tipografia conformes a dynapps-brand

CONTENIDO
[ ] Aporta valor real al lector (no es autopromocion disfrazada)
[ ] Tiene un objetivo claro (educar, nutrir, convertir)
[ ] Incluye datos/ejemplos/casos cuando hace afirmaciones
[ ] La longitud es apropiada para el canal
[ ] Tiene un CTA claro y unico

IDIOMA (es-ES)
[ ] Acentos correctos (a, e, i, o, u con tilde donde corresponde)
[ ] Signos de apertura (¿ ¡) donde aplica
[ ] "Ordenador" (no "computadora"), "movil" (no "celular")
[ ] Sin anglicismos innecesarios (usar equivalente espanol si existe)
[ ] Gramatica y ortografia revisadas

SEO (solo contenido web)
[ ] Title tag con keyword
[ ] Meta description con keyword + CTA
[ ] H1 unico con keyword
[ ] URL slug limpio
[ ] Internal links (min 2-3)
[ ] Alt text en imagenes
```
