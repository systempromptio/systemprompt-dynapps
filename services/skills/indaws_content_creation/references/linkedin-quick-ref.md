# LinkedIn Quick Reference — Indaws Content Creation

**Full rules**: Delegate to `linkedin-content-manager` for detailed templates and visual briefs.

## Quick Rules

| Elemento | Regla |
|----------|-------|
| Longitud | 80-350 palabras segun tipo |
| Hook | 2 lineas que provocan el "ver mas" |
| Cuerpo | Valor, historia o insight. Sin autopromocion directa |
| CTA | En el cuerpo (pregunta o invitacion). Enlaces en primer comentario |
| Hashtags | CERO |
| Emojis | CERO |
| Funnel | 2 TOFU + 2 MOFU + 1 BOFU por semana |

## Channel Writing Guide

| Aspecto | Guia |
|---------|------|
| Longitud | 80-350 palabras segun tipo |
| Tono | Conversacional experto, thought leadership |
| Estructura | Hook + cuerpo + CTA. Lineas cortas, espaciado generoso |
| Engagement | Terminar con pregunta abierta |
| Links | Solo en primer comentario, nunca en el cuerpo |
| Visual | Siempre acompanar de imagen/carrusel. Brief en el post |
| Frecuencia | 5 posts por semana (L-V) |
