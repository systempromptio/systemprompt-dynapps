## Uso de la Toma de Datos

Cuando el campo `xx_data_collection` esta disponible, el LLM debe:

1. **Extraer pain points explicitos**: Buscar frases como "actualmente...", "el problema es...", "necesitamos..."
2. **Identificar procesos actuales**: Que herramientas usan, como trabajan hoy
3. **Detectar prioridades**: Que mencionan primero, que repiten, que enfatizan
4. **Mapear a flujos**: Usar la tabla de mapeo para seleccionar flujos que resuelvan los pains detectados
5. **Personalizar talking points**: Adaptar el lenguaje al vocabulario del cliente

La toma de datos tiene PRIORIDAD sobre la deteccion por sector/keywords cuando hay contradiccion.
