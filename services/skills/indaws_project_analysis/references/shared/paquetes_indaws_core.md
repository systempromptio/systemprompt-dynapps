# Catálogo de Paquetes Indaws Core

Este documento contiene todos los paquetes de Indaws Core disponibles para extender las funcionalidades estándar de Odoo.

**Total de paquetes disponibles**: 42 paquetes

---

## Índice por Área Funcional

- **CRM y Ventas**: Monitorización IA, fidelización, flujo de aprobación, descuentos múltiples
- **Compras y Proveedores**: Gestión de proveedores, códigos por cliente
- **Inventario y Logística**: Albaranes valorados, almacenamiento externo, trazabilidad
- **Contabilidad**: OCR facturas, IPC, SII, VeriFacTu
- **RRHH**: Fichaje por proyecto, portal empleado, asistencias
- **Fabricación**: Gestión de producción, BOMs
- **Proyectos**: Materiales de proyecto, servicios de campo
- **E-commerce**: Prestashop, portal avanzado, feeds de productos
- **Marketing**: Email marketing avanzado
- **Integraciones**: Framework API, conectores externos
- **Reporting**: Generador PDFs personalizados
- **Movilidad**: App móvil nativa
