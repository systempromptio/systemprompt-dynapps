# Modelo de Competencias por Nivel

**CONFIDENTIAL - HR TEAM ONLY**

Definicion de competencias y expectativas por nivel profesional en Indaws.
Usado como referencia en evaluaciones de desempeno y decisiones de promocion.

---

## Competencias Core (Todos los niveles)

### 1. Comunicacion

| Nivel | Expectativa (Cumple = 3) |
|-------|--------------------------|
| IC1 | Comunica con claridad en su equipo. Pide ayuda cuando la necesita. Documenta su trabajo basico. |
| IC2 | Comunica proactivamente estado y bloqueos. Participa en reuniones de equipo con contribuciones relevantes. |
| IC3 | Comunica efectivamente cross-equipo. Presenta informacion compleja de forma accesible. Documenta decisiones tecnicas. |
| IC4 | Influye en decisiones a nivel de area. Facilita discusiones tecnicas complejas. Produce documentacion de referencia. |
| IC5 | Comunica vision tecnica a nivel de empresa. Mentoriza en comunicacion. Representa externamente. |
| IC6 | Define la narrativa tecnica de la organizacion. Thought leader externo. |
| M1 | Comunica objetivos y expectativas al equipo. Da feedback claro y constructivo. Facilita reuniones productivas. |
| M2 | Comunica estrategia del area. Alinea equipos cross-funcionales. Gestiona comunicacion de cambios. |
| M3 | Comunica direccion de la empresa. Influye en stakeholders de alto nivel. Portavoz institucional. |

### 2. Trabajo en Equipo

| Nivel | Expectativa (Cumple = 3) |
|-------|--------------------------|
| IC1 | Colabora con companeros directos. Acepta y da feedback basico. Es respetuoso con el equipo. |
| IC2 | Colabora efectivamente en proyectos de equipo. Comparte conocimiento. Ayuda a companeros bloqueados. |
| IC3 | Lidera colaboraciones cross-equipo. Mentoriza IC1-IC2. Facilita la resolucion de conflictos. |
| IC4 | Crea puentes entre equipos. Define practicas de colaboracion. Mentoriza IC3. |
| IC5 | Define cultura de colaboracion a nivel de area. Conecta iniciativas cross-empresa. |
| IC6 | Define cultura de colaboracion organizacional. Modelo de referencia. |
| M1 | Construye y mantiene un equipo cohesionado. Gestiona conflictos. Fomenta la seguridad psicologica. |
| M2 | Alinea multiples equipos. Gestiona dependencias cross-equipo. Desarrolla managers. |
| M3 | Define modelo de trabajo en equipo de la empresa. Gestiona dinamicas a nivel organizacional. |

### 3. Orientacion a Resultados

| Nivel | Expectativa (Cumple = 3) |
|-------|--------------------------|
| IC1 | Completa tareas asignadas en plazo. Cumple estandares de calidad basicos. |
| IC2 | Gestiona su carga de trabajo autonomamente. Cumple compromisos de forma fiable. Identifica riesgos. |
| IC3 | Entrega resultados de alto impacto. Prioriza efectivamente. Toma ownership de entregas del equipo. |
| IC4 | Entrega resultados transformadores. Define estandares de calidad. Multiplica el impacto de otros. |
| IC5 | Entrega resultados a nivel de empresa. Define prioridades estrategicas de su area. |
| IC6 | Entrega resultados que transforman la industria. Define la ambicion de la organizacion. |
| M1 | Asegura que el equipo entrega resultados. Gestiona impedimentos. Balancea velocidad y calidad. |
| M2 | Asegura resultados de multiples equipos. Gestiona trade-offs entre prioridades. |
| M3 | Asegura resultados de negocio. Define KPIs y OKRs de empresa. |

### 4. Adaptabilidad

| Nivel | Expectativa (Cumple = 3) |
|-------|--------------------------|
| IC1 | Acepta cambios con actitud positiva. Aprende nuevas herramientas y procesos rapidamente. |
| IC2 | Se adapta a cambios de prioridades. Aprende de errores. Busca feedback para mejorar. |
| IC3 | Lidera la adaptacion del equipo a cambios. Propone mejoras de procesos. Aprende dominios nuevos. |
| IC4 | Anticipa cambios y prepara al equipo. Define estrategias de adaptacion. Innova en procesos. |
| IC5 | Define la agenda de cambio en su area. Transforma procesos a nivel de empresa. |
| IC6 | Lidera transformaciones organizacionales. Anticipa tendencias de la industria. |
| M1 | Ayuda al equipo a navegar el cambio. Comunica el "por que" detras de los cambios. |
| M2 | Gestiona el cambio a nivel de area. Minimiza resistencia. Asegura transiciones fluidas. |
| M3 | Define y lidera la transformacion organizacional. |

### 5. Resolucion de Problemas

| Nivel | Expectativa (Cumple = 3) |
|-------|--------------------------|
| IC1 | Resuelve problemas bien definidos con guia. Escala problemas complejos apropiadamente. |
| IC2 | Resuelve problemas con multiples soluciones posibles. Analiza opciones y elige la adecuada. |
| IC3 | Resuelve problemas ambiguos. Descompone problemas complejos. Toma decisiones fundamentadas. |
| IC4 | Resuelve problemas con alcance organizacional. Crea frameworks de decision. Anticipa problemas. |
| IC5 | Resuelve problemas estrategicos. Define enfoque para problemas sin precedentes. |
| IC6 | Resuelve problemas a nivel de industria. Crea nuevos paradigmas. |
| M1 | Ayuda al equipo a resolver problemas. Facilita toma de decisiones. No es bottleneck. |
| M2 | Resuelve conflictos entre equipos. Toma decisiones con informacion incompleta. |
| M3 | Resuelve problemas de negocio criticos. Define prioridades bajo presion. |

## Competencias de Liderazgo (Solo M1+)

### 6. Gestion de Equipos

| Nivel | Expectativa (Cumple = 3) |
|-------|--------------------------|
| M1 | 1:1s semanales efectivos. Da feedback oportuno. Gestiona performance. Contrata bien. |
| M2 | Desarrolla managers. Define estructura del area. Gestiona performance a escala. |
| M3 | Define modelo de gestion de la empresa. Construye bench de liderazgo. |

### 7. Vision Estrategica

| Nivel | Expectativa (Cumple = 3) |
|-------|--------------------------|
| M1 | Alinea el trabajo del equipo con objetivos de negocio. Planifica a 3-6 meses. |
| M2 | Define roadmap del area a 6-12 meses. Conecta con estrategia de empresa. |
| M3 | Define estrategia de empresa a 1-3 anos. Comunica vision. |

### 8. Desarrollo de Personas

| Nivel | Expectativa (Cumple = 3) |
|-------|--------------------------|
| M1 | Identifica fortalezas y areas de mejora. Crea planes de desarrollo. Da coaching regular. |
| M2 | Identifica y desarrolla talento de alto potencial. Planifica sucesion. |
| M3 | Define cultura de desarrollo. Sponsor de programas de talento a nivel de empresa. |

---

## Uso en Evaluaciones

1. Identificar el **nivel** del empleado (IC1-IC6, M1-M3)
2. Evaluar cada competencia contra la expectativa de **su nivel** (no del nivel superior)
3. Puntuar de 1 a 5 segun la escala del review framework
4. Un 3 significa que **cumple** la expectativa de su nivel de forma consistente
5. Un 4+ significa que ya demuestra comportamientos del nivel superior (senal de readiness)
6. Un 2 o inferior requiere plan de accion especifico
