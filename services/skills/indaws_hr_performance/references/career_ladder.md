# Career Ladder - Niveles de Carrera

**CONFIDENTIAL - HR TEAM ONLY**

Definicion de niveles de carrera en Indaws con expectativas detalladas para cada nivel.
Marco de referencia para evaluaciones de desempeno, promociones y contratacion.

---

## Tracks de Carrera

Indaws ofrece dos tracks de carrera paralelos e igualmente valorados:

1. **Individual Contributor (IC)**: IC1 a IC6 - Crecimiento en expertise y impacto tecnico/funcional
2. **Management (M)**: M1 a M3 - Crecimiento en liderazgo de personas y estrategia

El cambio de IC a M (o viceversa) es posible y no se considera una "rebaja".

---

## Track de Contribuidor Individual (IC)

### IC1 - Junior
| Dimension | Expectativa |
|-----------|-------------|
| Experiencia | 0-2 anos |
| Scope | Tareas individuales, bien definidas |
| Autonomia | Supervision directa. Pide ayuda proactivamente |
| Calidad | Cumple estandares basicos con revision |
| Aprendizaje | Absorbe conocimiento rapidamente. Formacion activa |
| Impacto | Individual: completa tareas asignadas |
| Comunicacion | Reporta progreso. Escala bloqueos |
| Ejemplo Dev | Desarrolla features sencillas con guia. Fix de bugs |
| Ejemplo Comercial | Apoya en prospecting y preparacion de demos |
| Ejemplo Consultoria | Configura modulos basicos con supervision |

### IC2 - Mid-Level
| Dimension | Expectativa |
|-----------|-------------|
| Experiencia | 2-4 anos |
| Scope | Proyectos completos dentro de su area |
| Autonomia | Supervision puntual. Gestiona su dia a dia |
| Calidad | Entrega trabajo de calidad sin revision constante |
| Aprendizaje | Profundiza expertise. Curiosidad proactiva |
| Impacto | Equipo: contribucion fiable y consistente |
| Comunicacion | Comunica proactivamente. Participa en discusiones |
| Ejemplo Dev | Desarrolla features de complejidad media. Code review |
| Ejemplo Comercial | Gestiona pipeline propio. Cierra deals medianos |
| Ejemplo Consultoria | Lidera workstreams de implementacion |

### IC3 - Senior
| Dimension | Expectativa |
|-----------|-------------|
| Experiencia | 4-7 anos |
| Scope | Proyectos complejos, multiples componentes |
| Autonomia | Autonomo en la mayoria de decisiones tecnicas |
| Calidad | Define y eleva estandares de calidad del equipo |
| Aprendizaje | Referente tecnico. Mentoriza IC1-IC2 |
| Impacto | Equipo: mejora procesos y resultados del equipo |
| Comunicacion | Comunica cross-equipo. Presenta a stakeholders |
| Ejemplo Dev | Arquitectura de modulos. Lidera decisiones tecnicas |
| Ejemplo Comercial | Cuentas estrategicas. Deals complejos multi-producto |
| Ejemplo Consultoria | Lider de proyecto. Relacion directa con cliente |

### IC4 - Staff / Especialista
| Dimension | Expectativa |
|-----------|-------------|
| Experiencia | 7-10 anos |
| Scope | Iniciativas cross-equipo con impacto en area |
| Autonomia | Define enfoque tecnico del area |
| Calidad | Crea frameworks de calidad reutilizables |
| Aprendizaje | Aprende dominios adyacentes. Conecta silos |
| Impacto | Area: impacto en multiples equipos |
| Comunicacion | Influye en decisiones a nivel de empresa |
| Ejemplo Dev | Arquitectura global. Tech lead sin gestion directa |
| Ejemplo Comercial | Key Account Manager. Estrategia de cuentas top |
| Ejemplo Consultoria | Practice Lead. Define metodologia de delivery |

### IC5 - Principal
| Dimension | Expectativa |
|-----------|-------------|
| Experiencia | 10-15 anos |
| Scope | Direccion tecnica del area |
| Autonomia | Define vision y roadmap tecnico |
| Impacto | Empresa: contribucion estrategica |
| Comunicacion | Representa a la empresa externamente |

### IC6 - Distinguished
| Dimension | Expectativa |
|-----------|-------------|
| Experiencia | 15+ anos, reconocimiento externo |
| Scope | Vision a largo plazo de la organizacion |
| Impacto | Industria: referente externo |
| Comunicacion | Portavoz tecnico. Thought leader |

## Track de Management (M)

### M1 - Team Lead / Manager
| Dimension | Expectativa |
|-----------|-------------|
| Personas | 3-7 reportes directos |
| Foco | Ejecucion del equipo + desarrollo de personas |
| Actividades clave | 1:1s semanales, feedback continuo, hiring, performance reviews, sprint/project planning |
| Indicadores | Productividad equipo, retencion, satisfaccion, delivery |
| Prerequisito | Minimo IC3 + competencias de liderazgo demostradas |
| Riesgo comun | Seguir haciendo IC work en vez de gestionar |

### M2 - Senior Manager / Head
| Dimension | Expectativa |
|-----------|-------------|
| Personas | 2-4 managers o equipos (8-20 personas) |
| Foco | Estrategia del area + desarrollo de managers |
| Actividades clave | Objetivos del area, presupuesto, hiring strategy, talent development, cross-functional alignment |
| Indicadores | Resultados del area, crecimiento, eficiencia, bench de liderazgo |
| Prerequisito | Minimo M1 con track record de resultados + vision estrategica |

### M3 - Director / VP
| Dimension | Expectativa |
|-----------|-------------|
| Personas | Multiples areas (20+ personas) |
| Foco | Estrategia de negocio + cultura |
| Actividades clave | P&L, estrategia, cultura, representacion externa, board communication |
| Indicadores | Resultados de negocio, crecimiento, posicionamiento, cultura |
| Prerequisito | Minimo M2 con impacto demostrado a nivel de empresa |

## Criterios de Promocion

| Criterio | Requisito |
|----------|-----------|
| Tiempo minimo en nivel actual | 12 meses |
| Evaluaciones de desempeno | Dos ciclos consecutivos con puntuacion >= 4 |
| Demostrar competencias del nivel superior | Evidencias claras y consistentes |
| Validacion | Calibracion de equipo + aprobacion de RRHH + Direccion |
| Momento | Se propone en ciclo de calibracion, efectiva en siguiente revision salarial |

### Readiness Assessment

| Estado | Criterio |
|--------|----------|
| **Listo para promocion** | Cumple todos los criterios. Demuestra competencias del nivel superior de forma consistente |
| **Casi listo** | Cumple la mayoria. 1-2 areas por desarrollar. Promover en proximo ciclo si progresa |
| **Necesita desarrollo** | Progresando pero necesita mas tiempo y experiencia. Plan de desarrollo especifico |
| **No apto actualmente** | No demuestra las competencias necesarias. Foco en cumplir expectativas del nivel actual |

## Transiciones IC <-> M

| Transicion | Consideraciones |
|-----------|-----------------|
| IC3 -> M1 | Transicion mas comun. Requiere formacion en gestion. Periodo de adaptacion de 6 meses |
| IC4 -> M2 | Posible para perfiles con vision estrategica. Requiere experiencia de gestion previa |
| M1 -> IC3/IC4 | Retorno valido. No es una "rebaja". Nivel IC segun expertise demostrado |
| M2 -> IC4/IC5 | Menos comun pero posible. Valorar expertise tecnico actual |
