# Cross-Skill Integrations

Skills that benefit from organizational hierarchy data produced by org-chart.

## Already using HR hierarchy (enhanced with full org data)

- **ticket-report** — Full hierarchy enables multi-level rollups and department-wide views
- **timesheet-report** — Full hierarchy enables scaled team aggregation beyond direct reports
- **odoo-mentor** — Pre-built hierarchy context replaces per-session discovery

## Project management (team structure, resource allocation)

- **project-health-monitor** — Org structure contextualizes bottlenecks and resource availability
- **project-health-fixer** — Team hierarchy identifies who to reassign tasks to
- **project-plan** — Department dependencies and reporting lines improve task distribution
- **project-analysis** — Identifies affected departments and stakeholders per module

## Customer-facing (client org context)

- **service-desk** — Client org structure helps route tickets to responsible parties
- **demo-script-generator** — Client hierarchy personalizes demos, identifies decision-makers
- **lead-data-collection** — Org structure data scopes implementation

## Collaboration & events

- **event-planner** — Auto-populate attendees from departments, task assignment by reporting line
- **linkedin-content-manager** — Team expertise areas for content attribution
