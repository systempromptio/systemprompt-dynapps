# Content Review Checklist

Before delivering any Dynapps content, verify all items below. Voice rules in
[`verbal-identity.md`](verbal-identity.md); visual rules in [`brand-system.md`](brand-system.md).

## Voice Compliance
- [ ] Professional "tú" address (never "usted")
- [ ] Zero emojis
- [ ] Ortografía es_ES completa (acentos, eñes, diéresis)
- [ ] Value vocabulary used (no "gasto", "problema", "precio")
- [ ] Long-form explanatory style (no quick tips or bullet-only content)
- [ ] Soft "no" pattern applied where declining requests

## Visual Compliance
- [ ] Solo paleta, tipografía y logos de **Dynapps** según [`brand-system.md`](brand-system.md) (NO colores/fuentes de otra marca)
- [ ] Logo: colocación y clear-space según brand-system
- [ ] Gradientes / fondos según los modos definidos en brand-system
- [ ] Imágenes tratadas según las reglas de marca

## Format-Specific
- [ ] HTML: dark hero + light body, CSS custom properties (ver [`html-documents.md`](html-documents.md))
- [ ] PDF: ver [`pdf-reports.md`](pdf-reports.md) + `pdf-renderer` skill para la generación técnica (Playwright)
- [ ] Presentations: 16:9, fondos por tipo de slide, sin transiciones llamativas
- [ ] Social media: dimensiones correctas por plataforma, hashtags al final, sin emojis inline (ver [`social-media.md`](social-media.md))
