# Vocabulary & Terminology Reference

## Tabla de Vocabulario Indaws

| USAR (siempre) | NO USAR (nunca) | Razon |
|----------------|-----------------|-------|
| **inversion** | coste, gasto, precio | Reframing positivo: es una inversion con retorno |
| **reto** | problema | Connotacion de superacion vs negatividad |

| **evolucion continua** | mantenimiento | Crecimiento constante, no solo "mantener" |
| **especialistas** | tecnicos | Transmite expertise, no solo habilidad tecnica |
| **propuesta** | presupuesto | Presenta valor, no solo numeros |
| **implementacion** | instalacion | Un ERP se implementa (proceso), no se instala (producto) |
| **solucion** | herramienta, producto | Foco en resolver, no en el objeto |
| **equipo** | plantilla, empleados | Humaniza, transmite colaboracion |
| **oportunidad** | crisis, urgencia | Enfoque positivo en el cambio |

## Mencion de Competidores

Reglas para mencionar competidores en contenido:

```
1. Siempre neutral y factual. Nunca despectivo
2. Nombrar solo cuando aporta valor comparativo al lector
3. No usar terminos como "inferior", "peor", "obsoleto"
4. Formato: "A diferencia de [X], Odoo ofrece [beneficio]"
   NO: "[X] es limitado/caro/antiguo"
5. En comparativas directas, ser justo: reconocer fortalezas ajenas
6. Nunca nombrar competidores en LinkedIn o redes sociales
7. Competidores directos (otros Odoo partners): mencion solo si
   contexto lo requiere, siempre con respeto profesional
```
