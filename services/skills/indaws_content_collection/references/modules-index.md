## Data Schema

Each module record in `data/modules.json` contains:
- `id`: Odoo product ID
- `name`: Display name (includes the [CORE] marker)
- `technical_name`: Slug derived from the name (snake_case)
- `category`: Odoo product category (may be empty)
- `code`: Product code
- `description`: Full description
- `features`: Array of feature descriptions
- `price`: List price
- `url`: Product page URL
- `related_cases`: Array of case study IDs using this module
- `related_videos`: Array of video IDs about this module
