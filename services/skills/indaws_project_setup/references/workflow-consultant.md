# Consultant Workflow (Step 4)

## Workspace structure

Check if the project directory has any organization. If empty or scattered files, propose:

```
{project_dir}/
├── imports/      ← CSV/Excel files for data imports
├── exports/      ← Exported data, reports
├── docs/         ← Analysis documents, meeting minutes
├── templates/    ← DOCX templates, email templates
└── screenshots/  ← Odoo screenshots for documentation
```

Ask: "Want me to create these folders?" — Options: `Yes` / `No, my project is already organized`

If the project already has meaningful subdirectories, skip the proposal entirely.
