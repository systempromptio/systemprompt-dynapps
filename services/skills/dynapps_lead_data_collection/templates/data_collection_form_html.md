# HTML Template: Data Collection Form for Odoo

## Usage

This template produces the HTML stored in the crm.lead field `xx_data_collection`. It is
the CLEAN version of the form (no `[PREFILLED - …]` markers).

**Inline styles are mandatory** (Odoo does not process external CSS).

> **Language.** The English strings below are placeholders for structure. **Every visible string
> in the generated HTML goes out in the output language** — section titles, labels, the colour
> legend, the pending marker, the footer. One language per form. See SKILL.md `## Critical`.

**Data placeholders** (from the extraction JSON):

- `{opportunity_name}` — crm.lead name
- `{partner_name}` — res.partner name
- `{date}` — generation date (locale-appropriate format)
- `{sales_rep_name}` — sales rep name
- `{sources_analysed}` — text listing the sources used

**Content placeholders** (generated by the LLM):

- `{general_profile_rows}` — HTML rows of the general profile table
- `{objectives_rows}` — HTML rows of the objectives table
- `{modules_part_a}` — HTML blocks of detected modules (Part A)
- `{modules_part_b}` — HTML blocks of additional modules (Part B)
- `{customisations_content}` — HTML content of the customisations section
- `{migration_content}` — HTML content of the data migration section
- `{commercial_info_rows}` — HTML rows of the commercial information table
- `{pending_label}` — the localised visible pending marker (`[ASK]`, `[PREGUNTAR]`, `[TE VRAGEN]`…)

**RULES**

- No `[PREFILLED - …]` markers — the clean version carries values directly
- Confirmed rows: white background on BOTH cells (label + value)
- Pending rows: yellow (`#fff3cd`) on BOTH cells (label + value), with a specific question
- NEVER include assumptions, hypotheses or inferred data — only 100% verified information
- Include the colour legend at the top of the form (after the header)
- Inline styles on every element
- Main colour: `#714B67` (Odoo violet)

## Table Row Formats (Sections 1, 2, 6)

### Row with a pre-filled value (clean, no source marker)

```html
<tr>
  <td style="padding: 8px 12px; border: 1px solid #e0e0e0; font-weight: bold; color: #714B67; width: 200px; vertical-align: top;">
    {field_label}
  </td>
  <td style="padding: 8px 12px; border: 1px solid #e0e0e0;">
    {value}
  </td>
</tr>
```

### Pending row (yellow on BOTH cells)

```html
<tr>
  <td style="padding: 8px 12px; border: 1px solid #e0e0e0; font-weight: bold; color: #714B67; width: 200px; vertical-align: top; background-color: #fff3cd;">
    {field_label}
  </td>
  <td style="padding: 8px 12px; border: 1px solid #e0e0e0; background-color: #fff3cd;">
    <strong>{pending_label}</strong> {specific_question}
  </td>
</tr>
```

**IMPORTANT**: the value cell must carry a specific question the rep can put straight to the
client. Never just the bare marker.
Example: `<strong>[PREGUNTAR]</strong> ¿Cuántos usuarios necesitarán acceso al sistema?` in a
Spanish form; `<strong>[ASK]</strong> How many users will need access to the system?` in English.

## Pending Row Styles

When a field is pending, apply the yellow background to **BOTH cells** of the row (label + value):

```
/* Label cell (pending) */
padding: 8px 12px; border: 1px solid #e0e0e0; font-weight: bold; color: #714B67; width: 200px; vertical-align: top; background-color: #fff3cd;

/* Value cell (pending) */
padding: 8px 12px; border: 1px solid #e0e0e0; background-color: #fff3cd;
```

This highlights the **whole row** in light yellow so the rep spots every pending question at a
glance when opening the form in Odoo.

**NEVER** use orange (`#FFF3E0`) and never apply the background to the value cell alone. The
yellow must cover the ENTIRE row.

## Note on the Internal Chatter Note (mail.message)

Alongside the HTML form in `xx_data_collection`, an **internal note** is created on the
lead's chatter with an executive summary — also in the output language:

```html
<div style="font-family: Arial, sans-serif; font-size: 13px; color: #333;">
  <p><strong>Data collection prepared</strong> - {date}</p>
  <p>The data collection form was generated from:</p>
  <ul>
    <li>The opportunity description</li>
    <li>{n} chatter messages analysed</li>
    <li>{n} attachments reviewed</li>
    <li>Client website: {website}</li>
  </ul>
  <p><strong>Modules detected</strong>: {part_a_module_list}</p>
  <p><strong>Pre-filled fields</strong>: {n_prefilled} | <strong>Pending questions</strong>: {n_pending}</p>
  <p style="color: #888; font-size: 11px;">The complete form is in the "AI Data Collection" field of this opportunity.</p>
</div>
```
