# Messaging Frameworks — Competitive Analysis

## Messaging Matrix Dimensions

Compare each competitor across these dimensions:

| Dimension | How to evaluate | Where to find |
|-----------|----------------|---------------|
| **Positioning statement** | Core value proposition on homepage hero section | Website homepage |
| **Tagline / slogan** | Brand tagline if present | Website, LinkedIn, marketing materials |
| **Key differentiators** | Top 3 claimed advantages | About page, service pages |
| **Target audience** | Who they explicitly address | Website copy, case studies |
| **Tone of voice** | Formal/informal, technical/accessible | All content |
| **Call to action** | Primary CTA language and offer | Homepage, service pages |
| **Social proof** | Type and volume of testimonials, logos, certifications | Website, Google reviews |

## Analysis Questions

After completing the matrix, answer:
1. Where do positioning statements overlap? (commoditized messaging)
2. Which differentiators are unique to Indaws? (defensible advantages)
3. Which competitor messaging resonates most with our ICP? (threat assessment)
4. What positioning territory is unclaimed? (opportunity)
5. How does international backing (Dynapps) compare to competitors' structures?
