# guide/

This folder is for onboarding material that doesn't belong in `rules/` or `skills/` — e.g. runbooks,
walkthroughs, or reference docs for humans joining a project built on this accelerator.

Project initialization itself is no longer documented here — it's packaged directly into the
`/project:init` and `/project:sync` commands (see `commands/project-init.md` and
`commands/project-sync.md`), so it can be invoked directly instead of read and followed manually.

Drop future onboarding guides, skill write-ups, etc. here.
