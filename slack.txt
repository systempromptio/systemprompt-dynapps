Prod release: Google Workspace + Salesforce connectors — what needs setting

Four new keys go into .systemprompt/profiles/production/secrets.json (the file
`just deploy` ships; there is no CLI for secrets). Add these alongside the
existing keys — do not remove anything:

{
  "google_drive_mcp_client_id":     "<Google OAuth client ID>",
  "google_drive_mcp_client_secret": "<Google OAuth client secret>",
  "salesforce_mcp_client_id":       "<ECA consumer key>",
  "salesforce_mcp_client_secret":   "<ECA consumer secret>"
}

Google (GCP project 402649471530, the one holding the workspace-search engine)
- OAuth 2.0 Client ID, type Web application
- Authorized redirect URI:
    https://astound.systemprompt.io/api/public/connectors/google_workspace/callback
- Consent screen scopes: openid, email,
    https://www.googleapis.com/auth/discoveryengine.readwrite
- discoveryengine.googleapis.com must be enabled in that project
- The existing prod keys google_rag_mcp_client_id/secret are the old RAG
  connector and are read by nothing; if it is the same OAuth client, copy the
  values under the new names above.

Salesforce (one packaged External Client App, created in Astound US, installed
into Astound UK from deploy/salesforce/)
- Callback registered on the ECA:
    https://astound.systemprompt.io/api/public/connectors/salesforce/callback
- Consumer key -> salesforce_mcp_client_id
  Consumer secret -> salesforce_mcp_client_secret
  (shared by every org; subscriber orgs resolve to the source org's key)
- The existing prod keys salesforce_client_secret / salesforce_private_key are
  legacy: the first is unused, the second is only the optional JWT-bearer
  admin path, which no org enables. Neither is needed for this release.

Also required — YAML, not secrets (services/config/salesforce-orgs.yaml):
- salesforce-crm-us.my_domain: replace https://REPLACE-astound-us.my.salesforce.com
- salesforce-crm-uk.my_domain: replace https://REPLACE-astound-uk.my.salesforce.com
  Both must be the real HTTPS My Domain origins; consent is rejected until then.
- Decide whether salesforce-crm-dev (Developer Edition org, super_admin only)
  ships or is dropped from services/mcp + config.yaml includes + rules.yaml.

Until the four secrets exist, the server boots fine but each connector shows
"not provisioned" on the Connectors page.
