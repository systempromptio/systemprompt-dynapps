Dynapps gateway {{ include "dynapps.tag" . }} - release {{ .Release.Name }} in {{ .Release.Namespace }}.

{{- if .Values.migrate.enabled }}
1. The schema was migrated by the hook Job {{ $fullname }}-migrate before any pod rolled:
     kubectl -n {{ .Release.Namespace }} logs job/{{ $fullname }}-migrate -c migrate
{{- end }}
2. The gateway, api (console, MCP and agent routes) and worker (scheduler,
   MCP and agent processes; one holds the lease, the rest stand by) pods:
     kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
     kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ $fullname }}-api
     kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ $fullname }}-worker
     kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ $fullname }}-gateway
3. Readiness (503 {"status":"saturated"} means the pod is shedding load):
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullname }}-gateway 8080:{{ .Values.service.port }}
     curl -s localhost:8080/readyz
4. Public URL: {{ .Values.profile.externalUrl }}  (sign in at /admin/login, AD FS SSO)

Shared web volume: {{ .Values.pod.sharedWeb.existingClaim | default "none (no api pods)" }}. The worker
renders web/ and services-cache/ into this ReadWriteMany claim and the api pods
serve them read-only; the chart refuses to render api pods without it.
{{- if not .Values.networkPolicy.allowPublicHttps }}

NOTE: networkPolicy.allowPublicHttps is false. Providers outside Google (e.g. the
api.anthropic.com failover) are unreachable until you add them to
networkPolicy.extraEgress, and *.googleapis.com must resolve to Private Google
Access ranges.
{{- end }}
